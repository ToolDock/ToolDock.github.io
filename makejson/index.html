使い方

入力欄にJSONを貼り付けて、目的に応じてボタンを押します。 文法に誤りがある場合は、エラーの内容がその場で表示されます。

  • 整形する— 改行とインデントを入れて読みやすい形に直します
  • 圧縮する— 改行と空白をすべて取り除き、1行にまとめます。通信量を減らしたいときに使います
  • コピー— 処理後の内容をクリップボードにコピーします

入力欄の下には、文字数・行数・データサイズが表示されます。 圧縮の前後で比べると、どれだけ小さくなったかが分かります。

JSONの書き方のルール

JSONは見た目がJavaScriptのオブジェクトに似ていますが、書ける内容はより厳格です。 次の点でよくエラーになります。

ルール正しい例誤りの例
キーは必ずダブルクォートで囲む{"name": "A"}{name: "A"}
文字列はシングルクォート不可"A"'A'
末尾にカンマを置かない[1, 2][1, 2,]
コメントは書けない—// メモ
真偽値・空値は小文字true / false / nullTrue / NULL
数値の先頭に + や 0 を付けない5+5 / 05

よくあるエラーと原因

メッセージよくある原因
Unexpected token …その位置に想定外の文字があります。カンマの過不足やクォートの種類を確認してください
Unexpected end of JSON inputかっこが閉じていません。コピー時に末尾が切れていないか確認してください

整形と圧縮の使い分け

人が読んで確認するとき、差分を見比べるときは整形を使います。 一方、APIへ送る、設定値として1行で埋め込む、通信量を抑えたい場合は圧縮が向いています。 どちらもデータの中身は変わらないため、行き来しても情報は失われません。

よくある質問

Q. 貼り付けたJSONは送信されますか？
A. 送信されません。処理はすべてブラウザ上で行われるため、 業務データを貼り付けても外部には出ません。

Q. 日本語が含まれていても大丈夫ですか？
A. 問題ありません。そのままの文字で保持されます。

Q. キーの順番を並べ替えられますか？
A. このツールでは並べ替えは行わず、元の順序のまま整形します。

Q. どのくらいの大きさまで扱えますか？
A. 明確な上限は設けていませんが、数MBを超えると動作が重くなることがあります。
